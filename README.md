# Opleiding brandveiligheid

Webapp met de opleiding brandveiligheid voor het psychiatrisch ziekenhuis, WZC Sint-Alexius, WZC Passionisten, WZC Huize Nazareth en PSC Leuven.

De teksten worden beheerd in de bewerkbare versie op claude.ai. Deze repository bevat de publieke versie om te bekijken (GitHub Pages).
